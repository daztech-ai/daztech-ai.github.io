Phase 3 — First settled proof

~1 week

20-30 settled bets with calibration holding. The honest test: Brier and ROI from live picks match or beat the 26-season EPL backtest.

#TaskWhyDogfood gate
3.1 Daily cron: BABS scrape → engine run → settle Replaces "nudge Daz to make it work" pattern. 3 consecutive days, zero manual intervention
3.2 Backtest 2c features against 26-season EPL Features were merged on real data; calibration needs the matching backtest. Brier < 0.21 OR ROI ≥ 0, logit both
3.3 Racing: B/C-grade scraper, second source Doubles sport coverage, second test of the data plane. Same as 2.1, racing table populated
3.4 Calibration drift detector Without this, rig reverts to "0/100 because model silently broke". Detector fires on synthetic injected drift, alerting path works
Honest success criterion for Phase 3
  1. Brier and ROI from settled bets match or beat the EPL backtest
  2. If they don't: the rig-vs-EPL gap is a real problem, not a backtest artefact — Phase 4 becomes "fix the gap", not "ship"
