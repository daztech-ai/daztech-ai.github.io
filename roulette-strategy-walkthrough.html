Roulette: $200 → $1,000

A target-oriented walkthrough for a single-zero roulette wheel. Four $50 bullets. No reloads.

$200starting bankroll
$50one bullet
$1,000stop target
0reloads
Operating rule: Track the actual bankroll. Previous wins are not free money. Never increase the next stake to recover a loss.

Flow

Phase 1$25 + $25 overlapping even-money bets
Phase 2$100 on one dozen or column
Phase 3Target-sized bet to reach $1,000

Phase 1 — two overlapping bets

Place $25 on each of two overlapping even-money bets. Suitable pairs include:

  • Red + High
  • Black + Low
  • Red + Even
  • Black + Odd

Do not use opposing pairs such as Red + Black, High + Low, or Odd + Even. Those cannot produce a 2/2 result.

ResultBankroll effectAction
2/2+$50Enter Phase 2
1/2$0Repeat Phase 1
0/2−$50Record one bullet; repeat Phase 1

On a single-zero wheel with a suitable pair: 2/2 = 9/37, 1/2 = 18/37, and 0/2 = 10/37. Stop after four $50 losses.

Phase 2 — one dozen or column

After a 2/2 Phase 1 result, place $100 on one dozen or one column. Any of the three options has the same probability.

  • Win: +$200 profit; enter Phase 3.
  • Loss: −$100; reset to Phase 1 only if at least $50 remains.

Do not split the $100 across two dozens in this target version. The single bet provides the profit needed to fund the Phase 3 target bet.

Phase 3 — target-sized bet

After Phase 2 wins, use the current bankroll to select the matching target bet:

The final case uses a six-number line paying 5:1: $140 produces $700 profit, taking $300 to $1,000.

  • Win: stop immediately at $1,000 or above.
  • Loss: subtract the stake; reset to Phase 1 only if at least $50 remains.

Worked example

  1. Start with $200.
  2. Phase 1 returns 1/2. Bankroll remains $200; repeat.
  3. Phase 1 returns 0/2. Bankroll becomes $150; one bullet is used.
  4. Phase 1 returns 2/2. Bankroll becomes $200; enter Phase 2.
  5. Phase 2 wins. The bankroll becomes $400.
  6. Phase 3 uses $300 on one dozen.
  7. The dozen wins. The bankroll reaches $1,000. Stop.
