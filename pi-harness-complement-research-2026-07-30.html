Subject: pi-mono

pi-mono github.com/badlogic/pi-mono

Mario Zechner's monorepo shipping four packages under @earendil-works: pi-coding-agent, pi-agent-core, pi-ai, pi-tui. Runs on Node ≥ 22.19.0, MIT licensed (2025). MIT-style supply-chain hardening via pinned exact-version deps and .npmrc save-exact + min-release-age=2. No built-in permission system — external isolation via Gondolin / Docker / OpenShell required.

MCP & Spec

⚠️ 2026-07-28 MCP spec break

Moved from bidirectional stateful to stateless request/response. Retired initialize / initialized and Mcp-Session-Id. Added server/discover, header-based routing (Mcp-Method, Mcp-Mname), cacheable list results with ttlMs / cacheScope, Multi Round-Trip Requests. Any pi MCP work should target the new stateless model.

Cross-cutting Observations

1. Pi's biggest gaps are also its biggest integration opportunities

  • No permission system → fill via Gondolin micro-VM, Docker, OpenShell, or borrow from cline.
  • No built-in Slack/chat surface → fill via earendil-works/pi-chat or OpenClaw.
  • No native indexing → fill via claude-context (MCP).
  • No native memory → fill via mem0 / cognee / graphiti.
  • No native eval → fill via openbench.

2. 2026-07-28 MCP spec break is the single largest ecosystem-wide change

Stateless request/response, no more initialize / Mcp-Session-Id, new server/discover + header routing + cacheable list results. Any pi MCP work should target the new model.

3. OpenClaw is the natural messaging counterpart

pi-mono's own README delegates Slack/chat to earendil-works/pi-chat; OpenClaw owns 25+ channels (WhatsApp, Telegram, Slack, Discord, Google Chat, Signal, iMessage, SMS via Twilio, IRC, MS Teams, Matrix, Feishu, LINE, Mattermost, Nextcloud Talk, Nostr, Synology Chat, Tlon, Twitch, Zalo, QQ, WebChat). A combined pi-coding-agent + OpenClaw-Gateway stack covers the full local-AI-assistant surface.

4. opentui is the strongest pi-tui alternative

Unique advantage: SSH transport for serving TUI apps remotely. Already proven in production by OpenCode.

5. Pi's supply-chain hardening is a real differentiator

Exact-version pins + min-release-age=2. Bumblebee is a natural complement that extends the same posture to the runtime/installed-software surface.
